# Мобільний застосунок "TextQuest"
**Дисципліна:** Розробка проблемно-орієнтованих мов програмування для мобільних та ігрових застосунків <br>
**Студент:** Марк Дмитрієв  
**Група:** KS51  

---

## Про репозиторій

Цей репозиторій містить вихідний код мобільного застосунку у жанрі "Текстовий квест". Розробка велася поетапно в рамках виконання лабораторних робіт. 
Для зручності перевірки та збереження історії розробки, **кожна лабораторна робота винесена в окрему гілку**. Гілка `main` містить фінальну версію коду, що об'єднує всі реалізовані функції.

---

## Навігація по лабораторних роботах

Щоб перевірити конкретну лабораторну роботу, будь ласка, перемкніться на відповідну гілку. **У кожній гілці є свій детальний `README.md`** зі звітом, скріншотами та описом виконаних вимог.

* **[Лабораторна робота №1: Архітектура та навігація](../../tree/features/lab-1)**
  * Визначення доменних моделей сутностей (`QuestCampaignModel`, `QuestSceneModel`, `QuestChoiceModel`).
  * Налаштування навігації (`Jetpack Navigation Compose`).
  * Розробка базових UI-екранів на `Mock` даних.

* **[Лабораторна робота №2: Локальне сховище та API](../../tree/features/lab-2)**
  * Інтеграція локальної бази даних SQLite через `Room`.
  * Реалізація стратегії "Offline-first".
  * Налаштування `Repository Pattern` та імітація REST API мережевих запитів.

* **[Лабораторна робота №3: WebSocket та Тестування](../../tree/features/lab-3)**
  * Підключення real-time каналу зв'язку через `OkHttp WebSocket`.
  * Реактивне оновлення інтерфейсу без перезавантаження (`StateFlow`).
  * Покриття бізнес-логіки Unit-тестами (`JUnit4`, `MockK`).

* **[Лабораторна робота №4: Біометрична автентифікація](../../tree/features/lab-4)**
  * Інтеграція `androidx.biometric` для доступу за Face ID / Touch ID.
  * Збереження налаштувань безпеки локально у `SharedPreferences`.
  * Захист екрану входу та критичних дій (видалення даних).
